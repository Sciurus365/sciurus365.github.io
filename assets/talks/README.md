# Talk slides

Store presentation slide files here, organized by year:

```text
assets/talks/
  README.md
  2026/
    bnu-complex-dynamic-systems-psychology-slides.pdf
```

Use a descriptive lowercase filename with hyphens, such as
`institution-or-conference-short-talk-title-slides.pdf`. Keep slide files for a given
talk in that talk's year folder. Link to them from `_pages/talks.md` using a path under
`/assets/talks/`.
